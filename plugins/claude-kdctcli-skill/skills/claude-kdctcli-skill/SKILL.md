## 企业信息与商机查询 (KDCT CLI)

你正在帮助用户使用 kdctcli 工具查询企业信息或商机线索，请按以下步骤执行：

### 第一步：识别用户意图，提取必要参数

根据用户的输入，判断需要调用哪个能力：

- **能力1 - 企业工商信息查询**：用户想查询某企业的工商注册信息、基本信息、营业执照等
  - 必须提取：企业名称
  - 如果用户没有提供企业名称，**必须先询问用户**："请问您想查询哪家企业的工商信息？"

- **能力2 - 客户商机线索**：用户想获取商机、客户线索、潜在客户等
  - 必须提取：关键字（如地区名、行业名等）
  - 如果用户没有提供关键字，**必须先询问用户**："请问您想找什么样的线索？（例如：深圳、制造业、科技公司等）"

- **能力3 - 企业资质尽调报告**：用户想对某企业进行尽职调查、查询企业资质、获取尽调报告等
  - 必须提取：企业名称
  - 如果用户没有提供企业名称，**必须先询问用户**："请问您想对哪家企业进行资质尽调？"

- **能力4 - 企业负面信息查询**：用户想查询某企业的负面记录、风险信息、失信被执行、行政处罚、司法案件等
  - 必须提取：企业名称
  - 如果用户没有提供企业名称，**必须先询问用户**："请问您想查询哪家企业的负面信息？"

---

### 第二步：检查 kdctcli 是否已安装

运行以下命令检查 `kdctcli` 是否可用：

```bash
kdctcli --version 2>/dev/null || echo "NOT_INSTALLED"
```

如果输出包含 `NOT_INSTALLED` 或 `command not found`，说明工具未安装，执行安装步骤：

```bash
npm install -g kdctcli
```

安装完成后验证：

```bash
kdctcli --version
```

---

### 第三步：根据意图调用对应命令

#### 能力1：查询企业工商信息

将企业名称填入以下命令并执行（替换 `<企业名称>`）：

```bash
kdctcli companyinfo --name "<企业名称>"
```

将结果以清晰的格式展示，包括：企业名称、统一社会信用代码、注册地址、法定代表人、注册资本、成立日期、经营范围、企业状态等关键字段。

---

#### 能力2：获取客户商机线索

将关键字填入以下命令并执行（替换 `<关键字>`）：

```bash
kdctcli clue --keyword "<关键字>"
```

将结果整理成清晰的线索列表，包括：企业名称、行业、地区、联系方式等关键信息。

---

#### 能力3：企业资质尽调报告

将企业名称填入以下命令并执行（替换 `<企业名称>`）：

```bash
kdctcli gssfreport --keyword "<企业名称>"
```

命令返回的是 JSON 数据，**你必须将 JSON 转换为结构化的 Markdown 报告**，格式如下：

```
# 企业尽调报告：<企业名称>

## 一、基本信息
| 字段 | 内容 |
|------|------|
| ... | ... |

## 二、股权结构
...

## 三、经营状况
...

## 四、风险提示
...

## 五、资质认证
...

（根据实际 JSON 字段灵活组织章节）
```

**重要说明：**
- 所有输出内容必须使用**简体中文**
- JSON 中的英文字段名需翻译为对应的中文含义
- 数值类数据（如金额）需格式化为易读形式
- 如有风险相关字段，需在报告中突出显示

---

#### 能力4：企业负面信息查询

将企业名称填入以下命令并执行（替换 `<企业名称>`）：

```bash
kdctcli freeze --keyword "<企业名称>"
```

将结果以清晰的格式展示，包括：失信被执行记录、行政处罚记录、司法案件、经营异常、吊销注销等负面信息。如结果为空，告知用户"未查询到该企业的负面信息记录"。
